## کارهای باقی‌مانده

### ۱. ثبت کلید امضا در GitHub
فایل‌های کلید در پوشه‌ی `amozeshyar-android-signing` داخل پوشه‌ی کاربری ویندوز است (نه در ریپو).

GitHub ← Settings ← Secrets and variables ← Actions ← New repository secret:

| Secret | مقدار |
|---|---|
| `ANDROID_KEYSTORE_PASSWORD` | از `SECRETS.txt` |
| `ANDROID_KEY_PASSWORD` | از `SECRETS.txt` (همان رمز) |
| `ANDROID_KEY_ALIAS` | `release` |
| `ANDROID_KEYSTORE_BASE64` | کل متن `release.jks.base64.txt` |

بعد: Actions ← Android ← Run workflow. خروجی باید `app-release.apk` هم داشته باشد.

- [ ] از پوشه‌ی کلید یک نسخه‌ی پشتیبان بیرون از لپ‌تاپ گرفته شد (password manager یا فلش رمزدار)
- [ ] بعد از ثبت secretها، `release.jks.base64.txt` پاک شد

> اگر کلید گم شود، برای اپ منتشرشده دیگر نمی‌شود آپدیت داد.

اثر انگشت کلید (SHA-256)، برای مارکت‌ها:
`F2:0D:ED:4C:3C:F8:5C:6B:8E:F6:83:C7:48:AB:F8:CA:63:F7:A9:63:70:15:5F:D0:88:C6:51:27:7E:3D:65:3C`

### ۴. iOS (PWA)
iOS به‌جای اپ native، PWA دارد: کاربر سایت را در Safari باز می‌کند، دکمه‌ی Share و بعد «Add to Home Screen» را می‌زند. آیکون با نام همان سایت روی صفحه‌ی اصلی می‌آید و بدون نوار Safari باز می‌شود. یک راهنمای کوچک هم ۱۵ ثانیه بعد از ورود به سایت به کاربر آیفون همین را می‌گوید (با بستنش تا یک ماه نمایش داده نمی‌شود). کد آن در `frontend/` است، نه این پوشه.

واترمارک روی آیفون: ویدیو با `playsinline` داخل صفحه پخش می‌شود و دکمه‌ی تمام‌صفحه‌ی iOS به یک «تمام‌صفحه‌ی داخلی» تبدیل می‌شود که واترمارک را نگه می‌دارد (`components/player/VideoPlayer.vue`).

محدودیت‌های PWA در iOS (از سمت اپل، قابل رفع نیستند):
- جلوگیری از اسکرین‌شات و ضبط صفحه ممکن نیست؛ فقط واترمارک ایمیل بیننده بازدارنده است.
- مارکت ندارد؛ نصب فقط از خود سایت.

تست روی آیفون:
- [ ] راهنمای نصب بعد از ۱۵ ثانیه بیاید و با بستن دیگر نیاید
- [ ] Add to Home Screen: آیکون سبز کتاب و نام سایت
- [ ] باز شدن از آیکون بدون نوار Safari، ورود حفظ شود
- [ ] پخش ویدیو، خرید با زرین‌پال، ویس در چت
- [ ] ویدیو داخل صفحه پخش شود (نه خودکار تمام‌صفحه) و واترمارک دیده شود
- [ ] دکمه‌ی تمام‌صفحه‌ی iOS: پخش‌کننده کل صفحه را بپوشاند، واترمارک بماند، پخش قطع نشود، دکمه‌ی × برگرداند
- [ ] حالت هواپیما ← صفحه‌ی «اتصال برقرار نیست»

اگر بعداً اپ native iOS لازم شد: همین پروژه‌ی Capacitor خروجی iOS هم می‌دهد، ولی مک (یا Codemagic) و حساب Apple Developer لازم دارد.

## نکته‌های مهم

- **build محلی ممکن نیست:** `dl.google.com` به IP ایران ۴۰۴ می‌دهد. APK فقط در GitHub Actions ساخته می‌شود.
- **شناسه‌ی پکیج** (`site.modaresyar.app` یا شناسه‌ی هر مدرس) بعد از اولین انتشار نباید عوض شود.
- **برای هر مدرس:** Run workflow با آدرس سایت، شناسه و نام همان مدرس. برای آیکون اختصاصی، SVGهای `assets/` عوض و `npm run assets` اجرا شود.
- اپ سایت زنده را باز می‌کند، پس تغییرات سایت بدون نسخه‌ی جدید اپ به کاربران می‌رسد. فقط تغییرات native (این پوشه) نسخه‌ی جدید لازم دارند.
- یک اپ جداگانه هم برای نسخه‌ی دیگر محصول وجود دارد که ربطی به این یکی ندارد.
